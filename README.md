# Growfinix-Internship-ML-Task2-Credit-Card-Fraud-Detection
Machine Learning project for detecting credit card fraud transactions using Python and Isolation Forest as part of the Growfinix Machine Learning Internship.

# Credit Card Fraud Detection using Machine Learning

## Growfinnix Machine Learning Internship

### Task 2: Finance – Credit Card Fraud Detection (Imbalanced Data)

## Objective

The objective of this project is to identify fraudulent credit card transactions using Machine Learning techniques. Since fraud cases are rare compared to normal transactions, the project focuses on handling imbalanced data and detecting anomalies.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn

## Machine Learning Algorithm

* Isolation Forest

## Project Workflow

1. Import the required libraries.
2. Create or load the transaction dataset.
3. Check for missing values.
4. Select features and target values.
5. Split the dataset into training and testing sets.
6. Train the Isolation Forest model.
7. Predict fraudulent transactions.
8. Calculate and display the model accuracy.

## Output

The program displays:

* First five rows of the dataset
* Missing value information
* Model accuracy
* Task completion message
